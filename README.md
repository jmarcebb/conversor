# Conversor de temperaturas

Programa en Python que convierte temperaturas de grados Celsius a Fahrenheit y de Fahrenheit a Celsius.

## Requisitos

- Python 3
- Git

## Instalación

```bash
git clone https://github.com/mrtcebjj/conversor.git
cd conversor
```

## Uso

```bash
python conversor.py
```

## Documentación

```bash
pip install mkdocs
mkdocs serve
mkdocs build
```
